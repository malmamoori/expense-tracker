# Expense Tracker

A desktop expense tracking application built with Python, Tkinter, and SQLite.

## Features

- Add and manage expenses
- Organize expenses by category
- Track monthly expenses
- Track yearly expenses
- Search and view expense records
- Store expense data locally using SQLite
- Simple desktop user interface

## Technologies

- Python
- Tkinter
- SQLite

## Run

Run the application with:

```bash
python main.py
```

## Privacy

Expense data is stored locally in:

```text
expenses.db
```

The database file is excluded from GitHub using `.gitignore` to keep personal expense data private.
